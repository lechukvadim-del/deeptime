DeepTime.fun — статический сайт

1. Распакуйте архив.
2. На GitHub откройте репозиторий и загрузите index.html (Add file → Upload files).
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Перед публикацией отредактируйте цены привилегий и добавьте ссылку Discord, если нужно.

IP сервера уже указан: mc.DeepTime.fun.
